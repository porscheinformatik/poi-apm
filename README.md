# Porsche Informatik APM (Agent Package Manager) Repository

This repository contains common Agents, Instructions, Prompts and Skills.

It acts as repository for the [Agent Package Manager](https://microsoft.github.io/apm/).

## Install

```
apm install porscheinformatik/poi-apm
```

## Contents

Have a look at the [APM Summary](APM_SUMMARY.md) for an overview of the contents (generated with `/create-apm-summary`).
